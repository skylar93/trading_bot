## 테스트 에러 수정 및 리팩토링 가이드 (1/25/2025, 2:13:55 PM)

_**User**_



아주 많은 테스트 에러들이 보이네요. 하나씩 보면, 대부분 인자 이름이나 클래스 이름이 변경되면서 생긴 문제들입니다. 예컨대,
	•	TradingEnvironment.__init__() got an unexpected keyword argument ‘df’
	•	RiskConfig.__init__() got an unexpected keyword argument ‘max_position’
	•	BaseBacktester.__init__() got an unexpected keyword argument ‘initial_balance’
	•	…

이런 것들 대부분은 기존 코드/테스트에서 initial_balance→initial_capital, df→data, max_position→max_position_size(?) 등으로 인자 이름이 변경된 뒤, 테스트가 그걸 모르고 예전 인자를 사용**해서 발생합니다.

또한, 다양한 파일(예: test_backtest_execution.py, test_cicd.py, test_integration.py 등)에서,
	•	from training.utils.risk_backtest import RiskAwareBacktester
	•	TradingEnvironment(df=df, …)
	•	RiskConfig(max_position=…)

이런 식으로 레거시 import나 레거시 파라미터 이름을 사용하고 있는 게 원인입니다.

개별 에러 유형별 해결책
	1.	“TradingEnvironment.init() got an unexpected keyword argument ‘df’”
	•	새 TradingEnvironment는 __init__에서 data: Optional[pd.DataFrame] = None으로 받습니다.
	•	예전에는 TradingEnvironment(df=some_df) 식으로 썼나 봅니다.
	•	해결: 테스트 코드/프로덕션 코드에서 TradingEnvironment(df=...) 호출부를 TradingEnvironment(data=...)로 교체.
	2.	“RiskConfig.init() got an unexpected keyword argument ‘max_position’”
	•	현재 RiskConfig에는 max_position_size 필드가 있을지도 모르고, 혹은 max_position 필드가 없는 상태.
	•	해결: 코드를 보니 RiskConfig 클래스에는 max_position_size: float = 0.2 정도로 되어 있을 수 있음.
	•	테스트 코드에서 RiskConfig(max_position=0.5)처럼 예전 인자를 쓰고 있으면 → RiskConfig(max_position_size=0.5)로 바꿔주거나, max_position 라벨을 max_position_size로 수정해준다.
	3.	“BaseBacktester.init() got an unexpected keyword argument ‘initial_balance’”
	•	현재 BaseBacktester는 initial_capital로 받음.
	•	해결: 기존에 “Backtester(data=data, initial_balance=10000)”처럼 되어 있는 부분을 “BaseBacktester(data=data, initial_capital=10000)”로 수정.
	4.	테스트에서 “Momentum agent should follow upward trend” → assert array([0.]) > 0
	•	이건 논리 테스트 실패(값이 0.0인데 >0을 기대).
	•	해결: 에이전트 로직이나, 에이전트가 0.0 action을 반환하게 된 이유를 확인해야 합니다.
	•	임시로 테스트를 바꾸기보다, 정말 momentum agent가 upward trend에서 양수 액션을 반환하게 만들어야 함.
	5.	“Should execute some trades -> assert len([]) > 0”
	•	즉, 실제로는 트레이드가 하나도 발생하지 않아서 test fail.
	•	해결: 1) 테스트가 만든 액션이 0이었거나, 2) TradingEnvironment나 BaseBacktester 구성이 달라져서 모든 trade가 skip되었을 가능성.
	•	원인을 찾아서 trade가 일어나게끔 action이 ±0.1 이상이 되도록 수정, 또는 min_trade_size같은 제한을 낮춰준다.
	6.	“max() arg is an empty sequence”
	•	보통은 flash crash 시나리오에서 max(portfolio_values[:max_drawdown_idx])가 비어 있음.
	•	즉, max_drawdown_idx가 0 이상이지만 slice가 잘못되었거나, portfolio_values가 아예 빈 list일 수도.
	•	해결: 시나리오가 실제로 포트폴리오 값을 기록하도록 ensure(“trades happen” or “there is data”). 아니면 guard check: if len(portfolio_values[:max_drawdown_idx])>0 before max(...).

	•	ex) TradingEnvironment(df=some_df) → TradingEnvironment(data=some_df)

	2.	**“initial_balance=”**로 그렙:

grep -R "initial_balance=" tests/  

	•	결과를 initial_capital=로 변경.

grep -R "RiskConfig(" tests/  

	•	만약 test 코드에서 RiskConfig(max_position=0.3)로 되어 있으면, RiskConfig(max_position_size=0.3)로 수정 (또는 RiskConfig에 max_position 필드를 추가해줄 수도 있지만, 되도록 통일).

	4.	수정한 뒤, git diff나 IDE diff로 변경사항을 한번에 보고 커밋.

2단계: 유사하게, 레거시 import “training/utils/risk_backtest” 없애기
	•	grep -R "training.utils.risk_backtest" tests/
	•	만약 “from training.utils.risk_backtest import RiskAwareBacktester”라면, 지금은 “from training.backtesting.risk_aware_backtester import RiskAwareBacktester” (deprecated) or “BaseBacktester(risk_manager=…)”로 수정.

3단계: 부분적으로 남은 “Backtester” or “ScenarioBacktester”
	•	grep -R "from training.backtest import Backtester" tests/
	•	grep -R "from training.advanced_backtest import ScenarioBacktester" tests/
	•	모두 “from training.backtesting.base_backtester import BaseBacktester” (또는 scenario mixin)로 교체.

4단계: Check environment constructor
	•	Tests complaining “TradingEnvironment.__init__() got an unexpected keyword argument 'df'” → fix to (data=some_df).
	•	If test complains about “Got an unexpected keyword argument 'max_position_size'”, but your code says max_position → unify naming. (Either rename param in your environment code to max_position_size or rename the test usage to max_position.)

5단계: Rerun all tests & fix logic errors
	•	Some tests might fail logically (like “Should generate buy signal on dip”). That means your agent or environment logic changed in a way that breaks the assumption. Decide if you want to update the agent or relax the test.

6단계: “No trades occur” problem
	•	If multiple tests expect trades but get zero trades, debug why actions are zero or environment skipping trades. Possibly:
	•	min_trade_size is too high
	•	agent returns 0 action
	•	environment is finished too soon
	•	Adjust your test or your default environment settings so that at least 1 trade happens, satisfying the test.

결론

이런 식으로 테스트와 코드의 인자/필드명 불일치를 전부 정정해주면, 대부분의 “unexpected keyword argument”류 에러는 해결됩니다. 또한 시나리오 테스트 등에서 “portfolio_values”가 비면 “max() arg is an empty sequence”가 나니, 시나리오 생성 + agent action 부분을 점검해, 실제로 데이터가 있고 트레이드가 일어나게 만들어줘야 합니다.

정리하자면,
	1.	대규모 인자명 변경 (df -> data, initial_balance -> initial_capital, max_position -> max_position_size 등)으로 인해 생긴 문제 → 테스트 코드를 동일한 인자명으로 수정.
	2.	레거시 import (training.utils.risk_backtest) 없애고, 현행 파일 구조 (training/backtesting/risk_aware_backtester)로 교체.
	3.	시나리오나 agent 논리 때문에 논리적인 테스트 실패(>0 vs ==0) → agent나 테스트를 조정.

단계별로 고친 뒤 다시 pytest를 돌리면, 대부분의 실패가 사라질 것입니다. 필요한 경우, agent나 scenario 로직 자체를 수정해주어야 합니다(예: momentum agent가 항상 0.0 action 반환하면 test fails).

이렇게 처리하면, “’df=‘ 등 레거시 인자” 에러들과 테스트 불일치 문제가 해결될 것입니다.

def create_env(env_config: Dict[str, Any]) -> TradingEnvironment:
    """Create trading environment from config

    Args:
        env_config: Environment configuration

    Returns:
        Trading environment instance
    """
    # Get data from config
    data = env_config.get("data", None)
    if data is None:
        raise ValueError("No data provided in env_config")

    # Handle different data types
    if isinstance(data, (list, tuple)):
        # Convert list of dictionaries to DataFrame
        if all(isinstance(d, dict) for d in data):
            max_len = max(
                len(v) if isinstance(v, (list, np.ndarray)) else 1
                for d in data
                for v in d.values()
            )
            normalized_data = {}
            for k, v in data[0].items():
                if not isinstance(v, (list, np.ndarray)):
                    v = [v] * max_len
                normalized_data[k] = v
            data = pd.DataFrame(normalized_data)

    # Ensure column names have '$' prefix
    if isinstance(data, pd.DataFrame):
        rename_dict = {}
        for col in ["open", "high", "low", "close", "volume"]:
            if col in data.columns:
                rename_dict[col] = f"${col}"

    def train(self) -> None:
        """Train the agent with MLflow tracking."""
        if self.env is None:
            raise ValueError(
                "Environment not set. Please set env before training."
            )
        if self.agent is None:
            raise ValueError(
                "Agent not set. Please set agent before training."
            )

        with self.mlflow_manager.start_run(
            run_name=f"training_{self.start_time}"
        ):
            # Log training parameters
            self.mlflow_manager.log_params(
                {
                    "window_size": self.window_size,
                    "trading_fee": self.trading_fee,
                    "batch_size": self.batch_size,
                    "learning_rate": self.learning_rate,
                    "num_episodes": self.num_episodes,
                }
            )

            self.results_df = pd.DataFrame()

            for episode in range(self.num_episodes):
                # Reset environment
                state, _ = self.env.reset()
                done = False
                episode_reward = 0
                portfolio_value = self.env.initial_capital

                while not done:
                    # Get action from agent
                    action = self.agent.get_action(state)

                    # Take step in environment
                    next_state, reward, done, truncated, info = self.env.step(
                        action
                    )

                    # Update agent
                    self.agent.train_step(
                        state, action, reward, next_state, done
                    )

                    # Update state and metrics
                    state = next_state
                    episode_reward += reward
                    portfolio_value = info.get(
                        "portfolio_value", portfolio_value
                    )
