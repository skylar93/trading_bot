## 테스트를 위한 에이전트 생성 수정 방법 (1/27/2025, 10:33:52 AM)

_**User**_

아래 답변에서는 테스트가 요구하는 형태(“아무런 인자 없이도 agent를 만들 수 있음”)에 맞춰서,
agent_factory.py 내부 로직을 수정해 테스트 에러를 해결하는 방법을 설명합니다.

문제 원인 요약
	1.	PPOAgent
	•	test_create_ppo_agent에서 create_agent("PPO")를 호출하지만,
	•	PPOAgent는 생성 시 “env” 혹은 “(observation_space, action_space)” 중 하나를 반드시 제공해야 함.
	•	아무 인자 없이 초기화하면 ValueError("Must provide either env or both observation_space and action_space") 에러 발생.
	2.	MeanReversionPPOAgent / MomentumPPOAgent
	•	현재 이들 클래스의 __init__ 시그니처는 보통 def __init__(self, config: Dict[str, Any]) 형태이므로,
	•	파라미터 config가 필수 인자인데, 테스트에서는 아무 인자 없이 create_agent("MeanReversion")를 부름 → TypeError: missing 1 required positional argument: 'config'.
	3.	MultiAgentManager
	•	생성자 __init__(self, agent_configs: List[Dict[str, Any]], device: str = "...").
	•	테스트에서 create_agent("MultiAgent") 호출 시, agent_configs가 없으므로 TypeError 발생.

즉, **테스트는 “에이전트를 인자 없이(또는 최소한의 config)로도 만들 수 있어야 한다”**는 전제로 작성되어 있습니다.
이를 만족하려면, 각 클래스가 요구하는 필수 인자(env, observation_space/action_space, agent_configs 등)에 대해
기본값(default)을 부여하거나, agent_factory.py에서 자동으로 기본값을 세팅해야 합니다.

해결 전략

A. agent_factory에서 각 에이전트에 최소 인자 제공

테스트에서는 “아무런 인자 없이 agent 생성”을 시도합니다.
그러므로, create_agent 호출 시 내부적으로 필요한 최소 인자를 자동 제공하면 됩니다.

예시:
	1.	PPOAgent
	•	필수 요구사항: (env) 혹은 (observation_space, action_space).
	•	테스트에서는 안 줌 → 우리가 최소한의 Mock 관찰공간, 행동공간을 만들어 넘겨야 함.
	•	예:

import gym
import numpy as np

dummy_obs_space = gym.spaces.Box(low=-np.inf, high=np.inf, shape=(1,1), dtype=np.float32)
dummy_act_space = gym.spaces.Box(low=-1.0, high=1.0, shape=(1,), dtype=np.float32)

이렇게 아주 간단한 Box space를 기본으로 전달.

	2.	MeanReversionPPOAgent / MomentumPPOAgent
	•	생성자 __init__(self, config: Dict[str, Any]).
	•	최소한 config={} 식으로라도 넣어줘야 “missing 1 required positional argument: ‘config’”가 안 남.
	•	내부에서 “env or obs/action_space”가 필요하면, 마찬가지로 dummy space를 config 안에 넣어줄 수도 있음.
	3.	MultiAgentManager
	•	생성자 __init__(self, agent_configs: List[Dict[str,Any]], device=...).
	•	기본값 agent_configs=[]로 넘겨주면, 빈 리스트라도 주어지므로 TypeError 해소.

dummy_obs_space = gym.spaces.Box(low=-np.inf, high=np.inf, shape=(1, 1), dtype=np.float32)
dummy_act_space = gym.spaces.Box(low=-1.0, high=1.0, shape=(1,), dtype=np.float32)

def create_agent(agent_name: str, config: Optional[Dict[str, Any]] = None) -> Any:
    """
    Creates and returns an instance of the specified trading agent.
    """
    if config is None:
        config = {}

    # Special handling: If 'env' or 'observation_space' not in config for PPO-based agents,
    # we provide dummy spaces to avoid ValueError.
    if agent_name in ("PPO", "MeanReversion", "Momentum"):
        # Ensure we have minimal keys for PPO-like agents
        if "env" not in config and ("observation_space" not in config or "action_space" not in config):
            config["observation_space"] = dummy_obs_space
            config["action_space"] = dummy_act_space

    if agent_name == "Dummy":
        return DummyAgent(**config)

    elif agent_name == "PPO":
        # PPOAgent expects either env or obs/action_space
        return PPOAgent(**config)

    elif agent_name == "MeanReversion":
        # MeanReversionPPOAgent usually has signature __init__(self, config: Dict[str,Any])
        # But in your code, it might be different. Let's assume it is similar to PPOAgent
        # => We pass the entire config as a single named arg: config=config
        # or we have to do MeanReversionPPOAgent(**config).
        # If the current signature is: def __init__(self, config: Dict[str,Any]): 
        #   Then do: MeanReversionPPOAgent(config=config)
        return MeanReversionPPOAgent(config=config)

    elif agent_name == "Momentum":
        return MomentumPPOAgent(config=config)

    elif agent_name == "MultiAgent":
        # MultiAgentManager requires 'agent_configs' at minimum
        if "agent_configs" not in config:
            config["agent_configs"] = []
        return MultiAgentManager(**config)

    raise ValueError(f"Unsupported agent type: {agent_name}")

def list_available_agents() -> Dict[str, str]:
    """
    Returns a dictionary of available agent types and their descriptions.
    """
    return {
        "Dummy": "Simple dummy agent for testing",

        "MeanReversion": "Mean reversion strategy using PPO",
        "Momentum": "Momentum-based strategy using PPO",
        "MultiAgent": "Manager for multiple trading agents"
    }
