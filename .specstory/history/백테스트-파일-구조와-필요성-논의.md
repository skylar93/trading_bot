_**User**_

두 코드 모두 MLflow 실험을 손쉽게 관리하고, 여러 시나리오(런 시작/종료, 모델/데이터 로깅, 실험 삭제/재생성 등)를 지원한다는 점에서 목적이 유사합니다.
하지만 코드 구조나 초기화/정리 로직을 살펴보면, 다음과 같은 관점에서 “현대적이고 효율적인지”를 판단할 수 있습니다:

1. 초기화 로직(Experiment, Tracking URI) 단순화
	•	어떤 코드는 deleted experiment 처리, .trash 디렉터리 정리, dummy run 등을 수행해 DB 초기화한다.
	•	다른 코드는 좀 더 “직관적”으로 experiment_name이 있으면 바로 사용하고, 없으면 생성만 해둔 뒤, 더 복잡한 로직(예: 삭제/cleanup)은 최소화한다.

너무 많은 마법 같은 처리(e.g. deleted experiment를 자동으로 완전 삭제, dummy run 등)는 장점도 있지만,
사용자가 명시적으로 “실험 깨끗이 다시 만들고 싶다”라고 설정해야 하는 부분을 코드에서 자동 처리하면 “원치 않는 삭제”가 일어날 수도 있습니다.
반면 단순화된 로직(실험이 있으면 그대로, 없으면 만들기, nested run만 원하는 대로) 은 사용자 입장에서 동작이 예측 가능해서 유지보수 측면에서 나을 수 있습니다.

따라서 관점에 따라 다르지만, **“단순하고 명시적인 로직”**이 조금 더 현대적/유연하다고 볼 때가 많습니다.

2. Context Manager 사용 여부 및 명시적 start_run()/end_run()
	•	어떤 버전은 __enter__ / __exit__로 with MLflowManager as m: 형태를 쓰고, 내부에서 run을 시작/종료합니다.
	•	어떤 버전은 별도의 start_run(), end_run() 호출만 하고 context manager는 꼭 안 써도 됩니다.

최근 Pythonic한 스타일은 context manager를 적극 활용해 자원 정리를 자동화하는 쪽을 선호하는 경향이 있습니다.
그렇다고 꼭 모든 MLflow 로직에 with를 쓰는 것이 무조건 옳지는 않지만,
run을 시작하고, 내부에서 예외가 터져도 자동으로 end_run() 하게끔 설계한 코드는 안정성이 조금 더 높다고 평가할 수 있습니다.

3. 중복된 로직/메서드 개수 최소화

두 파일을 비교해보면, 모두:
	•	start_run(), end_run(), log_params(), log_metrics(), log_artifact(), log_model(), cleanup() 등이 유사하게 존재
	•	한쪽은 “dummy metric” 찍거나 “deleted experiment” 핸들링 등을 추가로 함

중복 로직이 많은 경우, 유지보수 시 한쪽만 고치고 다른 쪽에 반영이 안 되면 버그가 생기므로,
하나의 통합된 클래스로 합쳐서 if allow_deleted_cleanup: 같은 옵션 파라미터로 분기하는 편이 현대적인 추세(= “드라이(DRY) 원칙”).

4. 오류 처리 / 예외 로깅 방식
	•	일부 코드는 try/except 후 logger.error로 남기고 re-raise
	•	다른 코드는 warning만 찍고 넘어가거나, pass 하기도 함

“현대적”인 관점에서는,
	•	메서드별로 명확한 예외 처리 (필요하면 re-raise),
	•	로그에 충분한 context/info를 남기는 로직,
	•	(필요 시) 사용자에게 콜백/옵션으로 “deleted experiment”을 허용/금지할지 결정하도록 설계
등이 더 견고합니다.

5. 정리: 어느 쪽이 “더 현대적/효율적”인가?
	•	만약 “deleted experiment”를 자동 정리하고 dummy run 찍는 로직이 필요 없는 상황이라면,
간소한 로직(즉, 굳이 .trash 디렉터리를 지우거나 dummy metric을 찍지 않는 편)이 오히려 “가볍고 예측 가능”해서 “현대적”이라고 느낄 수 있습니다.
	•	Context manager를 지원해 예외 상황에서도 자동 end_run이 되게 하는 편이 더 Pythonic이고 안정적입니다.
	•	옵션 파라미터로 allow_deleted_experiment_cleanup, append_timestamp_to_name 등을 설정해주는 식이면, 사용자가 유연하게 선택 가능해집니다.

결론적으로,
**“단순화된 초기화 + context manager + 명시적 옵션 분기”**가 종합적으로 현대적이고 효율적인 설계로 평가받을 때가 많습니다.
어떤 프로젝트 환경/팀 스타일에 따라 다르겠지만,
불필요한 마법 로직(deleted experiment 강제 정리 등)은 꼭 필요한 시점에만 옵션으로 수행케 하고,
그 외에는 명시적으로 세팅하도록 하는 게 유지보수성이 높고 직관적입니다.

라고 말하네. 네 말도 맞는 것 같고. 일단 test를 통합해 보고 통합된 테스트 상황에 두 파일 모두 통과를 띄우는지를 봐야 될 것 같다. 중복되는 테스트는 합쳐 놓고. 그래야 합병을 할 때 어느 부분이 잘못되었는지 손쉽게 파악할 수 있을 것 같아. 그래서 일단, test 파일을 빠지는 부분 없이 합쳐 줘. 그다음에 파일을 합쳐 보자.

	•	어떤 버전은 __enter__ / __exit__로 with MLflowManager as m: 형태를 쓰고, 내부에서 run을 시작/종료합니다.
	•	어떤 버전은 별도의 start_run(), end_run() 호출만 하고 context manager는 꼭 안 써도 됩니다.

최근 Pythonic한 스타일은 context manager를 적극 활용해 자원 정리를 자동화하는 쪽을 선호하는 경향이 있습니다.
그렇다고 꼭 모든 MLflow 로직에 with를 쓰는 것이 무조건 옳지는 않지만,
run을 시작하고, 내부에서 예외가 터져도 자동으로 end_run() 하게끔 설계한 코드는 안정성이 조금 더 높다고 평가할 수 있습니다.

3. 중복된 로직/메서드 개수 최소화

두 파일을 비교해보면, 모두:
	•	start_run(), end_run(), log_params(), log_metrics(), log_artifact(), log_model(), cleanup() 등이 유사하게 존재
	•	한쪽은 “dummy metric” 찍거나 “deleted experiment” 핸들링 등을 추가로 함

중복 로직이 많은 경우, 유지보수 시 한쪽만 고치고 다른 쪽에 반영이 안 되면 버그가 생기므로,
하나의 통합된 클래스로 합쳐서 if allow_deleted_cleanup: 같은 옵션 파라미터로 분기하는 편이 현대적인 추세(= “드라이(DRY) 원칙”).

4. 오류 처리 / 예외 로깅 방식
	•	일부 코드는 try/except 후 logger.error로 남기고 re-raise
	•	다른 코드는 warning만 찍고 넘어가거나, pass 하기도 함

“현대적”인 관점에서는,
	•	메서드별로 명확한 예외 처리 (필요하면 re-raise),
	•	로그에 충분한 context/info를 남기는 로직,
	•	(필요 시) 사용자에게 콜백/옵션으로 “deleted experiment”을 허용/금지할지 결정하도록 설계
등이 더 견고합니다.

5. 정리: 어느 쪽이 “더 현대적/효율적”인가?
	•	만약 “deleted experiment”를 자동 정리하고 dummy run 찍는 로직이 필요 없는 상황이라면,
간소한 로직(즉, 굳이 .trash 디렉터리를 지우거나 dummy metric을 찍지 않는 편)이 오히려 “가볍고 예측 가능”해서 “현대적”이라고 느낄 수 있습니다.
	•	Context manager를 지원해 예외 상황에서도 자동 end_run이 되게 하는 편이 더 Pythonic이고 안정적입니다.
	•	옵션 파라미터로 allow_deleted_experiment_cleanup, append_timestamp_to_name 등을 설정해주는 식이면, 사용자가 유연하게 선택 가능해집니다.

불필요한 마법 로직(deleted experiment 강제 정리 등)은 꼭 필요한 시점에만 옵션으로 수행케 하고,

"""
Unified MLflow Manager
Combines functionality from mlflow_manager.py and mlflow_manager_new.py
"""

import os
import time
import shutil
import tempfile
import logging
from typing import Dict, Any, Optional
from pathlib import Path
from datetime import datetime

import mlflow
from mlflow.entities import RunStatus
import torch
import pandas as pd
import numpy as np

logger = logging.getLogger(__name__)


class MLflowManager:
    """
    Unified MLflow experiment tracking manager.

    Combines key functionalities:
    - Create / get experiment with optional deletion of 'deleted' experiment
    - Start / end run (supports nested runs)
    - Optionally logs a dummy metric to ensure run is active (if use_dummy_run=True)
    - Log params, metrics, artifacts, PyTorch models
    - Optional context manager usage (with MLflowManager(...)) 
      to auto-end runs even on exceptions
    - Freed or forcibly re-init experiment if `allow_deleted_experiment_cleanup=True`
    """

    def __init__(
        self,
        experiment_name: str,
        tracking_dir: Optional[str] = None,
        allow_deleted_experiment_cleanup: bool = True,  # <-- 추가 옵션
        use_dummy_run: bool = True,                    # <-- 추가 옵션
    ):
        """
        Args:
            experiment_name: MLflow experiment name
            tracking_dir: Directory to store MLflow artifacts & DB
            allow_deleted_experiment_cleanup: If True, 
                will forcibly remove 'deleted' experiment from MLflow store & .trash 
            use_dummy_run: If True, logs a small dummy run to ensure DB initialization
        """
        self.experiment_name = experiment_name
        self.allow_deleted_experiment_cleanup = allow_deleted_experiment_cleanup
        self.use_dummy_run = use_dummy_run

        # Decide on tracking_dir
        if tracking_dir:
            self.tracking_dir = Path(tracking_dir).absolute()
        else:
            # Default: home dir .mlflow_unified
            home_dir = Path.home()
            self.tracking_dir = home_dir / ".trading_bot_mlflow_unified"

        # Create directory
        os.makedirs(self.tracking_dir, mode=0o755, exist_ok=True)

        # Use file-based store (sqlite)
        db_path = self.tracking_dir / "mlflow.db"
        mlflow.set_tracking_uri(f"sqlite:///{db_path}")

        self._active_run = None

        # Initialize experiment
        self._initialize_experiment()

    def _initialize_experiment(self):
        """Initialize or get existing MLflow experiment, optionally removing 'deleted'."""
        try:
            # End any active runs 
            self.end_active_runs()

            experiment = mlflow.get_experiment_by_name(self.experiment_name)
            if experiment:
                if experiment.lifecycle_stage == "deleted":
                    logger.info(
                        f"Experiment '{self.experiment_name}' in 'deleted' stage."
                    )
                    if self.allow_deleted_experiment_cleanup:
                        logger.info(f"Cleaning up 'deleted' experiment: {self.experiment_name}")
                        mlflow.delete_experiment(experiment.experiment_id)

                        # Remove .trash, experiment folders, artifact location
                        trash_path = self.tracking_dir / ".trash"
                        if trash_path.exists():
                            shutil.rmtree(trash_path, ignore_errors=True)

                        exp_path = self.tracking_dir / str(experiment.experiment_id)
                        if exp_path.exists():
                            shutil.rmtree(exp_path, ignore_errors=True)
                        artifact_path = experiment.artifact_location.replace("file://", "")
                        if artifact_path and Path(artifact_path).exists():
                            shutil.rmtree(artifact_path, ignore_errors=True)

                        # Set experiment = None so we re-create
                        experiment = None
                        time.sleep(0.2)
                    else:
                        logger.warning(
                            "Experiment is deleted but 'allow_deleted_experiment_cleanup=False', "
                            "so reusing it might fail or cause unexpected behavior."
                        )
                        self.experiment_id = experiment.experiment_id
                else:
                    self.experiment_id = experiment.experiment_id
            if not experiment:
                # Create new
                artifact_location = os.path.join(
                    str(self.tracking_dir), 
                    "artifacts",
                    self.experiment_name
                )
                os.makedirs(artifact_location, mode=0o755, exist_ok=True)

                self.experiment_id = mlflow.create_experiment(
                    self.experiment_name, artifact_location=artifact_location
                )

            mlflow.set_experiment(self.experiment_name)

            # Optionally do a dummy run to init DB
            if self.use_dummy_run:
                with mlflow.start_run() as run_:
                    mlflow.log_metric("_dummy", 0.0)
                time.sleep(0.1)

        except Exception as e:
            logger.error(f"Failed to initialize MLflow experiment: {str(e)}")
            raise

    def end_active_runs(self):
        """End all active MLflow runs (including if we have a tracked _active_run)."""
        try:
            if self._active_run:
                mlflow.end_run()
                self._active_run = None

            while mlflow.active_run():
                mlflow.end_run()
        except Exception as e:
            logger.warning(f"Error ending active runs: {str(e)}")

    def start_run(
        self,
        run_name: Optional[str] = None,
        nested: bool = False,
        tags: Optional[Dict[str, Any]] = None,
    ):
        """Start a new MLflow run."""
        try:
            if nested and not mlflow.active_run():
                raise mlflow.exceptions.MlflowException(
                    "No active parent run found for nested run"
                )
            elif not nested:
                self.end_run()  # End any existing run in manager

            self._active_run = mlflow.start_run(
                run_name=run_name,
                nested=nested,
                tags=tags,
                experiment_id=self.experiment_id,
            )

            # Log dummy metric to ensure run is recognized
            if self.use_dummy_run:
                mlflow.log_metric("_dummy", 0.0)
                time.sleep(0.05)

            return self._active_run

        except Exception as e:
            logger.error(f"Failed to start MLflow run: {str(e)}")
            raise

    def end_run(self, status: str = "FINISHED"):
        """End the current MLflow run (if any)."""
        try:
            if mlflow.active_run():
                if self.use_dummy_run:
                    mlflow.log_metric("_dummy_end", 0.0)
                    time.sleep(0.05)
                mlflow.end_run(status=status)
                time.sleep(0.05)
            self._active_run = None
        except Exception as e:
            logger.error(f"Failed to end MLflow run: {str(e)}")
            raise

    def cleanup(self):
        """Clean up MLflow resources (end runs, remove tracking_dir)."""
        try:
            self.end_active_runs()
            if os.path.exists(self.tracking_dir):
                shutil.rmtree(self.tracking_dir, ignore_errors=True)
            time.sleep(0.1)
        except Exception as e:
            logger.warning(f"Failed to cleanup MLflow resources: {str(e)}")

    @property
    def experiment(self):
        """Return mlflow experiment object from experiment_id."""
        return mlflow.get_experiment(self.experiment_id)

    @property
    def active_run(self):
        """Return the current active run reference (if any)."""
        return self._active_run

    def log_params(self, params: Dict[str, Any]):
        """Log parameters to MLflow."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run found")
        mlflow.log_params(params)
        time.sleep(0.05)

    def log_metrics(self, metrics: Dict[str, float], step: Optional[int] = None):
        """Log metrics to MLflow."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run found")
        mlflow.log_metrics(metrics, step=step)
        time.sleep(0.05)

    def log_model(self, model: nn.Module, artifact_path: str):
        """Log PyTorch model to MLflow."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run found")
        with tempfile.NamedTemporaryFile(suffix=".pth", delete=False) as f:
            torch.save(model.state_dict(), f.name)
            mlflow.log_artifact(f.name, artifact_path=artifact_path)
            os.remove(f.name)
        time.sleep(0.05)

    def log_artifact(self, local_path: str, artifact_path: Optional[str] = None):
        """Log a file as artifact."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run found")
        mlflow.log_artifact(local_path, artifact_path=artifact_path)
        time.sleep(0.05)

    def log_dataframe(
        self, df: pd.DataFrame, artifact_path: str, filename: str
    ):
        """Log a DataFrame as artifact (in Parquet or JSON)"""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run found")

        suffix = ".parquet" if filename.endswith(".parquet") else ".json"
        temp_suffix = suffix
        with tempfile.NamedTemporaryFile(suffix=temp_suffix, delete=False) as f:
            if suffix == ".parquet":
                df.to_parquet(f.name)
            else:
                # default to JSON
                df.to_json(f.name, orient="records", lines=False)

            mlflow.log_artifact(f.name, os.path.join(artifact_path, filename))
            os.remove(f.name)
        time.sleep(0.05)

    def log_backtest_results(self, results: Dict[str, Any]):
        """
        Log dictionary with keys:
          "metrics" -> Dict
          "trades" -> pd.DataFrame
          "portfolio_values" -> pd.DataFrame
        """
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")

        # 1. Log metrics
        if "metrics" in results and isinstance(results["metrics"], dict):
            mlflow.log_metrics(results["metrics"])
            time.sleep(0.05)

        # 2. Log trades
        if "trades" in results and isinstance(results["trades"], pd.DataFrame):
            trades_df = results["trades"]
            self.log_dataframe(trades_df, artifact_path="backtest", filename="trades.parquet")

        # 3. Log portfolio values
        if "portfolio_values" in results and isinstance(results["portfolio_values"], pd.DataFrame):
            pf_df = results["portfolio_values"]
            self.log_dataframe(pf_df, artifact_path="backtest", filename="portfolio_values.parquet")

    def get_artifact_uri(self, artifact_path: str) -> str:
        """Get artifact URI for current run."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run found")
        return mlflow.get_artifact_uri(artifact_path)

    # Optionally we can define a context manager
    def __enter__(self):
        """Context manager entry -> start run (non-nested by default)."""
        self.start_run(run_name=None, nested=False)
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        """Context manager exit -> end run with status."""
        status = "FAILED" if exc_type is not None else "FINISHED"
        self.end_run(status=status)
        # no re-raise by default, unless user wants to raise it
        # but typically we let the exception pass through
        return False  # means "don't swallow exceptions"

```
"""Unified MLflow experiment tracking manager"""

import os
import time
import shutil
import tempfile
import logging
from typing import Dict, Any, Optional
from pathlib import Path
from datetime import datetime

import mlflow
from mlflow.entities import RunStatus
import torch
import torch.nn as nn
import pandas as pd
import numpy as np

logger = logging.getLogger(__name__)


class MLflowManager:
    """
    Unified MLflow experiment tracking manager.
    
    Features:
    - Create/get experiment with optional deletion of 'deleted' experiment
    - Start/end run (supports nested runs)
    - Optional dummy metric logging for run validation
    - Log params, metrics, artifacts, PyTorch models
    - Context manager support for automatic run management
    - Optional experiment cleanup and reinitialization
    """

    def __init__(
        self,
        experiment_name: str,
        tracking_dir: Optional[str] = None,
        allow_deleted_experiment_cleanup: bool = False,
        use_dummy_run: bool = False,
        append_timestamp: bool = False
    ):
        """Initialize MLflow manager.
        
        Args:
            experiment_name: Name of the MLflow experiment
            tracking_dir: Directory for MLflow artifacts & DB
            allow_deleted_experiment_cleanup: If True, forcibly remove 'deleted' experiments
            use_dummy_run: If True, logs a dummy metric for DB initialization
            append_timestamp: If True, appends timestamp to experiment name
        """
        # For test environments, optionally append timestamp
        if append_timestamp and experiment_name.startswith("test_"):
            timestamp = datetime.now().strftime("%Y%m%d_%H%M%S_%f")
            self.experiment_name = f"{experiment_name}_{timestamp}"
        else:
            self.experiment_name = experiment_name

        self.allow_deleted_experiment_cleanup = allow_deleted_experiment_cleanup
        self.use_dummy_run = use_dummy_run

        # Set up tracking directory
        if tracking_dir:
            self.tracking_dir = Path(tracking_dir).absolute()
        else:
            home_dir = Path.home()
            self.tracking_dir = home_dir / ".trading_bot_mlflow"

        # Create directory with proper permissions
        os.makedirs(self.tracking_dir, mode=0o755, exist_ok=True)

        # Set up MLflow tracking
        db_path = self.tracking_dir / "mlflow.db"
        mlflow.set_tracking_uri(f"sqlite:///{db_path}")

        self._active_run = None
        self._initialize_experiment()

    def _initialize_experiment(self):
        """Initialize or get existing MLflow experiment."""
        try:
            # End any active runs first
            self.end_active_runs()

            # Get or create experiment
            experiment = mlflow.get_experiment_by_name(self.experiment_name)
            if experiment:
                if experiment.lifecycle_stage == "deleted":
                    logger.info(f"Found deleted experiment: {self.experiment_name}")
                    if self.allow_deleted_experiment_cleanup:
                        logger.info("Cleaning up deleted experiment...")
                        mlflow.delete_experiment(experiment.experiment_id)
                        
                        # Clean up related directories
                        paths_to_clean = [
                            self.tracking_dir / ".trash",
                            self.tracking_dir / str(experiment.experiment_id),
                            Path(experiment.artifact_location.replace("file://", ""))
                        ]
                        for path in paths_to_clean:
                            if path.exists():
                                shutil.rmtree(path)
                        
                        experiment = None
                        time.sleep(0.2)  # Wait for cleanup
                    else:
                        logger.warning(
                            "Found deleted experiment but cleanup not allowed. "
                            "This may cause unexpected behavior."
                        )
                        self.experiment_id = experiment.experiment_id
                else:
                    self.experiment_id = experiment.experiment_id

            if not experiment:
                # Create new experiment
                artifact_location = os.path.join(
                    str(self.tracking_dir), "artifacts", self.experiment_name
                )
                os.makedirs(artifact_location, mode=0o755, exist_ok=True)
                
                self.experiment_id = mlflow.create_experiment(
                    self.experiment_name,
                    artifact_location=artifact_location
                )

            mlflow.set_experiment(self.experiment_name)

            # Optional dummy run
            if self.use_dummy_run:
                with mlflow.start_run() as run:
                    mlflow.log_metric("_dummy", 0.0)
                time.sleep(0.1)

        except Exception as e:
            logger.error(f"Failed to initialize experiment: {str(e)}")
            raise

    def end_active_runs(self):
        """End all active MLflow runs."""
        try:
            if self._active_run:
                mlflow.end_run()
                self._active_run = None

            while mlflow.active_run():
                mlflow.end_run()
        except Exception as e:
            logger.warning(f"Error ending active runs: {str(e)}")

    def start_run(
        self,
        run_name: Optional[str] = None,
        nested: bool = False,
        tags: Optional[Dict[str, Any]] = None,
    ):
        """Start a new MLflow run."""
        try:
            if nested and not mlflow.active_run():
                raise mlflow.exceptions.MlflowException(
                    "No active parent run found for nested run"
                )
            elif not nested:
                self.end_run()

            self._active_run = mlflow.start_run(
                run_name=run_name,
                nested=nested,
                tags=tags,
                experiment_id=self.experiment_id,
            )

            if self.use_dummy_run:
                mlflow.log_metric("_dummy", 0.0)
                time.sleep(0.05)

            return self._active_run

        except Exception as e:
            logger.error(f"Failed to start run: {str(e)}")
            raise

    def end_run(self, status: str = "FINISHED"):
        """End the current MLflow run."""
        try:
            if mlflow.active_run():
                if self.use_dummy_run:
                    mlflow.log_metric("_dummy_end", 0.0)
                    time.sleep(0.05)
                mlflow.end_run(status=status)
                time.sleep(0.05)
            self._active_run = None
        except Exception as e:
            logger.error(f"Failed to end run: {str(e)}")
            raise

    def cleanup(self):
        """Clean up MLflow resources."""
        try:
            self.end_active_runs()
            if os.path.exists(self.tracking_dir):
                shutil.rmtree(self.tracking_dir)
        except Exception as e:
            logger.warning(f"Failed to cleanup resources: {str(e)}")

    def log_metrics(
        self, metrics: Dict[str, float], step: Optional[int] = None
    ):
        """Log metrics to MLflow."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")
        mlflow.log_metrics(metrics, step=step)

    def log_params(self, params: Dict[str, Any]):
        """Log parameters to MLflow."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")
        mlflow.log_params(params)

    def log_model(self, model: nn.Module, artifact_path: str):
        """Log PyTorch model to MLflow."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")
        mlflow.pytorch.log_model(model, artifact_path)

    def load_model(self, run_id: str, artifact_path: str) -> nn.Module:
        """Load a PyTorch model from MLflow."""
        try:
            model_uri = f"runs:/{run_id}/{artifact_path}"
            return mlflow.pytorch.load_model(model_uri)
        except Exception as e:
            logger.error(f"Failed to load model: {str(e)}")
            raise

    def log_artifact(
        self, local_path: str, artifact_path: Optional[str] = None
    ):
        """Log a local file as an MLflow artifact."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")
        mlflow.log_artifact(local_path, artifact_path)

    def log_dataframe(
        self, df: pd.DataFrame, artifact_path: str, filename: str
    ):
        """Log DataFrame to MLflow."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")
        
        suffix = ".parquet" if filename.endswith(".parquet") else ".json"
        with tempfile.NamedTemporaryFile(suffix=suffix, delete=False) as f:
            if suffix == ".parquet":
                df.to_parquet(f.name)
            else:
                df.to_json(f.name, orient="records", lines=False)
            
            mlflow.log_artifact(f.name, os.path.join(artifact_path, filename))
            os.remove(f.name)

    def log_backtest_results(self, results: Dict[str, Any]):
        """Log backtest results including metrics, trades, and portfolio values."""
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")

        if "metrics" in results:
            self.log_metrics(results["metrics"])

        if "trades" in results and isinstance(results["trades"], pd.DataFrame):
            self.log_dataframe(
                results["trades"], "backtest", "trades.parquet"
            )

        if "portfolio_values" in results and isinstance(
            results["portfolio_values"], pd.DataFrame
        ):
            self.log_dataframe(
                results["portfolio_values"], 
                "backtest",
                "portfolio_values.parquet"
            )

    @property
    def experiment(self):
        """Get the current experiment."""
        return mlflow.get_experiment(self.experiment_id)

    @property
    def active_run(self):
        """Get the current active run."""
        return self._active_run

    def __enter__(self):
        """Context manager entry."""
        self.start_run()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        """Context manager exit."""
        status = "FAILED" if exc_type is not None else "FINISHED"
        self.end_run(status=status)
        return False  # Don't suppress exceptions
```

```
    def get_best_run(self, metric_name: str, mode: str = "max") -> Optional[mlflow.entities.Run]:
        """Get the best run based on a metric.
        
        Args:
            metric_name: Name of the metric to optimize
            mode: Either 'max' (default) or 'min'
            
        Returns:
            Best run or None if no runs found
        """
        try:
            client = mlflow.tracking.MlflowClient()
            runs = client.search_runs(
                [self.experiment_id],
                order_by=[f"metrics.{metric_name} {'DESC' if mode == 'max' else 'ASC'}"]
            )
            return runs[0] if runs else None
        except Exception as e:
            logger.error(f"Failed to get best run: {str(e)}")
            return None

    def list_runs(
        self,
        status: Optional[str] = None,
        order_by: Optional[List[str]] = None
    ) -> List[mlflow.entities.Run]:
        """List runs in the experiment.
        
        Args:
            status: Filter by run status (e.g., 'FINISHED', 'RUNNING', etc.)
            order_by: List of columns to sort by (e.g., ['metrics.accuracy DESC'])
            
        Returns:
            List of runs
        """
        try:
            client = mlflow.tracking.MlflowClient()
            filter_string = f"status = '{status}'" if status else None
            runs = client.search_runs(
                [self.experiment_id],
                filter_string=filter_string,
                order_by=order_by
            )
            return runs
        except Exception as e:
            logger.error(f"Failed to list runs: {str(e)}")
            return []

    def log_figure(
        self,
        figure: Any,
        artifact_path: str,
        filename: str,
        format: str = "png",
        **kwargs
    ):
        """Log a matplotlib/plotly figure as an artifact.
        
        Args:
            figure: matplotlib.Figure or plotly.Figure
            artifact_path: Directory within artifacts to save to
            filename: Name of the file (without extension)
            format: File format (default: 'png')
            **kwargs: Additional arguments passed to savefig/write_image
        """
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")

        try:
            with tempfile.NamedTemporaryFile(suffix=f".{format}", delete=False) as f:
                if hasattr(figure, "savefig"):  # matplotlib
                    figure.savefig(f.name, format=format, **kwargs)
                elif hasattr(figure, "write_image"):  # plotly
                    figure.write_image(f.name, format=format, **kwargs)
                else:
                    raise ValueError("Unsupported figure type")
                
                mlflow.log_artifact(f.name, os.path.join(artifact_path, filename))
                os.remove(f.name)
        except Exception as e:
            logger.error(f"Failed to log figure: {str(e)}")
            raise
```

```
    def log_figure(
        self,
        figure: Any,
        artifact_path: str,
        filename: str,
        format: str = "png",
        **kwargs
    ):
        """Log a matplotlib/plotly figure as an artifact.
        
        Args:
            figure: matplotlib.Figure or plotly.Figure
            artifact_path: Directory within artifacts to save to
            filename: Name of the file (without extension)
            format: File format (default: 'png')
            **kwargs: Additional arguments passed to savefig/write_image
        """
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")

        try:
            with tempfile.NamedTemporaryFile(suffix=f".{format}", delete=False) as f:
                if hasattr(figure, "savefig"):  # matplotlib
                    figure.savefig(f.name, format=format, **kwargs)
                elif hasattr(figure, "write_image"):  # plotly
                    figure.write_image(f.name, format=format, **kwargs)
                else:
                    raise ValueError("Unsupported figure type")
                
                # Ensure filename has extension
                if not filename.endswith(f".{format}"):
                    filename = f"{filename}.{format}"
                
                # Create full artifact path
                full_path = os.path.join(artifact_path, filename)
                mlflow.log_artifact(f.name, artifact_path)
                os.remove(f.name)
                
                # Sleep briefly to ensure file is saved
                time.sleep(0.1)
        except Exception as e:
            logger.error(f"Failed to log figure: {str(e)}")
            raise
```

```
    def get_artifact_uri(self, artifact_path: str) -> str:
        """Get the URI for an artifact.
        
        Args:
            artifact_path: Path to the artifact relative to the artifact root
            
        Returns:
            Full URI for the artifact
        """
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")
        return mlflow.get_artifact_uri(artifact_path)

    def log_backtest_results(self, results: Dict[str, Any], df_results: Optional[pd.DataFrame] = None):
        """Log backtest results including metrics, trades, portfolio values, and plots.
        
        Args:
            results: Dictionary containing:
                - metrics: Dict of metric values
                - trades: DataFrame of trades
                - portfolio_values: DataFrame of portfolio values
                - figures: Optional dict of matplotlib/plotly figures
            df_results: Optional DataFrame with additional results to log
        """
        if not mlflow.active_run():
            raise mlflow.exceptions.MlflowException("No active run")

        # Log metrics
        if "metrics" in results:
            self.log_metrics(results["metrics"])

        # Log trades
        if "trades" in results and isinstance(results["trades"], pd.DataFrame):
            self.log_dataframe(
                results["trades"], "backtest", "trades.parquet"
            )

        # Log portfolio values
        if "portfolio_values" in results and isinstance(
            results["portfolio_values"], pd.DataFrame
        ):
            self.log_dataframe(
                results["portfolio_values"], 
                "backtest",
                "portfolio_values.parquet"
            )

        # Log additional results DataFrame if provided
        if df_results is not None:
            self.log_dataframe(df_results, "backtest/data", "results.parquet")

        # Log figures
        if "figures" in results and isinstance(results["figures"], dict):
            for name, fig in results["figures"].items():
                self.log_figure(fig, "backtest/figures", f"{name}.png")
```

네, `mlflow_logger.py`와 `mlflow_manager.py`는 다른 파일입니다:

1. `MLflowLogger` (mlflow_logger.py):

- 기본적인 MLflow 작업(실험 생성, 실행 시작/종료, 메트릭/파라미터 로깅)에 중점

2. `MLflowManager` (unified_mlflow_manager.py):
- 더 포괄적인 MLflow 관리 기능 제공
- 실험 삭제/정리, 중첩된 실행, 더미 메트릭 등 고급 기능 포함

- 전반적인 MLflow 리소스 관리에 초점

현재는 `MLflowManager`가 더 많은 기능을 제공하고 있으며, 이것이 우리가 통합된 버전으로 선택한 이유입니다. `MLflowLogger`는 더 단순한 로깅 인터페이스가 필요한 경우에 사용될 수 있습니다.

1. 다른 목적과 책임:
- `MLflowLogger`: 단순하고 명확한 로깅 작업에 특화
- `MLflowManager`: 전반적인 MLflow 리소스 관리와 고급 기능 제공

2. 단일 책임 원칙(Single Responsibility Principle):
- `MLflowLogger`는 로깅이라는 하나의 책임에 집중
- `MLflowManager`는 실험 관리와 리소스 관리라는 별도의 책임을 가짐

3. 사용 사례의 차이:
- 간단한 로깅만 필요한 경우 → `MLflowLogger` 사용
- 실험 관리와 고급 기능이 필요한 경우 → `MLflowManager` 사용

4. 코드 유지보수:
- 각각의 클래스가 더 명확한 목적을 가지므로 유지보수가 쉬움
- 기능 추가나 수정 시 영향 범위가 명확함

따라서 이전의 통합 계획을 수정하고, 두 파일을 각각의 목적에 맞게 별도로 유지하는 것이 더 좋은 설계가 될 것 같습니다.
