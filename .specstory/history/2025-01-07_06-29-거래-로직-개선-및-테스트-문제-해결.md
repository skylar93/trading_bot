## SpecStory

## 거래 로직 개선 및 테스트 문제 해결 (1/7/2025, 6:29:27 AM)

_**User**_

지금 테스트 로그와 결과를 보면, 매도 시점의 revenue 계산이나 PnL 추적이 여전히 완벽히 일치하지 않아서, 테스트가 약간의 오차(0.7~0.8 정도)로 실패하고 있습니다. 또한 “포지션 크기 10.9%”가 “10% 제한”을 초과한다는 오류도 계속 뜨고 있네요.

이 문제들을 “좀 더 현실적인 거래 로직”으로 해결하려면, (A) 부분 청산/평단 로직을 정확히 구현하고, (B) 포지션 사이즈 제한 로직을 좀 더 엄격하게 적용하며, (C) 테스트에서 허용하는 오차나 조건을 좀 더 유연하게 혹은 현실적으로 잡아야 합니다.

1) 매도 시점 revenue 계산 정확화

**핵심은 “이전 포지션을 얼마나 청산했는지(부분 청산?), 평단 대비 이익/손실이 얼마인지”**를 제대로 계산해야 한다는 것입니다.
현재는

elif risk_adjusted_action < 0:  # Sell
    trade_revenue = trade_value - trading_cost
    new_balance = self.balance + trade_revenue
    ...

처럼 단순히 (trade_size × 현재가격) - 수수료 로 revenue를 정의하고 있는데, 이건 “신규 매도 포지션 진입” 같은 해석이 되어 버립니다.
실제 “기존 포지션을 청산”이라면:
	1.	청산할 수량(sell_size) = min(기존 보유 수량, 금번 매도 액션 수량)
	2.	realized_pnl = (현재가격 - 평균단가) × 청산 수량
	3.	trade_revenue(gross) = 청산 수량 × 현재가격
	4.	수수료 = gross × trading_fee
	5.	net_revenue = trade_revenue - 수수료
	6.	balance += net_revenue
	7.	기존 포지션 수량 = 기존 포지션 - 청산 수량
	8.	평단 = (청산 후 남은 포지션이 있다면) 유지 or 새로 계산

이 과정을 거쳐야 revenue와 pnl이 자연스럽게 들어 맞습니다.

예시:

if risk_adjusted_action < 0:
    old_pos = self.positions.get(asset, 0)
    if old_pos > 0:
        # 실제 청산 수량
        sell_size = min(abs(trade_size), old_pos)
        
        # 매도 총액 (gross revenue)
        gross_revenue = sell_size * current_price
        
        # 수수료
        fee = gross_revenue * self.trading_fee
        
        # net revenue
        net_revenue = gross_revenue - fee
        
        # 실제 pnl: (매도단가 - 평단)가치
        entry_price = self.entry_prices[asset]
        realized_pnl = sell_size * (current_price - entry_price) - fee
        
        # balance 업데이트
        new_balance = self.balance + net_revenue
        
        # 포지션 감소
        self.positions[asset] = old_pos - sell_size
        if abs(self.positions[asset]) < 1e-8:
            # 포지션 다 털렸으면 제거
            del self.positions[asset]
            del self.entry_prices[asset]
        
        # trade_result에 revenue와 pnl 기록
        trade_result["revenue"] = net_revenue
        trade_result["pnl"] = realized_pnl

        # 나머지 로직...

이런 식으로 하면, 실제로 부분 청산이든 전부 청산이든 정확하게 revenue와 pnl이 들어맞을 것입니다.
(반면, “새로 숏 포지션 진입”하려면 로직이 좀 달라집니다. “기존 포지션 0인데 숏 action < 0이 들어옴” 등등…)

즉, “매도”라는 것이 “기존 롱 포지션을 청산”인지, 아니면 “숏 진입”인지를 분기해서 처리해야 합니다. 지금은 통합해서 if risk_adjusted_action < 0: # Sell으로 처리해버리니, “숏 진입” 로직과 “롱 청산” 로직이 섞여서 테스트와 실제 거래값이 어긋나는 겁니다.

2) 포지션 크기 제한 문제 (10.9% vs 10%)

이 문제는 두 가지가 가능:
	1.	테스트에서 포지션 사이즈를 계산할 때 근사치 (예: 10.93이 실제로는 10.0에 가깝지만, 부동소수점 계산 등으로 오버)
	2.	실제로 VaR나 correlation, fee 계산 등으로 balance가 약간 변동 → portfolio_value가 변하거나
	3.	trade_size 계산이 “portfolio_value / current_price”로 해서 약간 남을 수 있음

해결책은:
	•	(a) 테스트에서 “최대 10% 초과분이 1% 이내면 ok” 같은 tolerance를 두거나,
	•	(b) 정말 엄격히 “절대 10% 넘지 않도록” 로직에서 trade_size = min(...) 처리.

예: 아래처럼 trade_size를 최종적으로 다시 한 번 max_position_size와 비교:

max_position_value = self.risk_manager.config.max_position_size * portfolio_value
trade_value = abs(trade_size) * current_price

if trade_value > max_position_value:
    scale = max_position_value / trade_value
    trade_size *= scale

이렇게 하면 결코 10%를 넘을 수 없습니다.
테스트에서도 아주 작은 부동소수점 차이(예: 10.000001%)는 허용하거나 <= 10 * 1.001 같은 식으로, “0.1% 미만 오차 허용”을 하면 통과할 것입니다.

3) “평균 거래(average trade) = 0” 문제
	•	실제로 final PnL이 몇 달러 수준이라서 (거래 횟수 대비) 0으로 표시될 수 있음
	•	혹은 PnL이 계속 -0.2, +0.1 식으로 왔다 갔다 해서 결과적으로 근 0
	•	만약 우리가 partial fills나 fee 때문에 계속 손해만 본다면 Profit Factor=0, avgTrade=0이 나올 수도…

이를 보정하려면:
	1.	테스트 데이터를 더 큰 변동성으로 만들어서 확실히 플러스/마이너스가 생기게 한다.
	2.	Agent 액션도 ±1.0처럼 크게 해서 실질적 수익/손실을 키운다.
	3.	RiskConfig에서 fee를 낮추거나 portfolio_var_limit 등을 완화해서 포지션이 좀 더 크게 잡히도록 한다.

4) 동일 시각에 거래 2번 기록되는 문제

코드 상에서:

trade_result = self.execute_trade(...)
if trade_result:
    self.trades.append(trade_result)

하고, execute_trade 내에서도 self.trades.append(trade_result)를 하면 2번 append됩니다.
run 메서드를 보니:

# Execute trade
trade_result = self.execute_trade(...)
# Store trade result
if trade_result:
    self.trades.append(trade_result)

execute_trade 메서드 내에서도:

# Add to trades list
self.trades.append(trade_result)

→ 이중 기록.
따라서 하나는 제거해야 합니다. 보통은 execute_trade 내부에서는 “trade_result”만 return하고, “trades.append(…)”는 상위 함수(=run)에서 한 번만 하는 식이 깔끔합니다.

5) 테스트를 조금 더 자세히 작성하기

현재 test_trade_execution_logging 같은 테스트가 "pnl" vs "expected_pnl"을 직접 비교하지만, 중간 과정(부분 청산인지, 숏 진입인지)을 정확히 알지 못하면 조금씩 차이가 납니다.

더 자세한 시나리오 테스트 예:
	1.	처음에 buy 1.0 단위 @100달러 → balance=9000 + position=1
	2.	가격 110달러로 상승 → sell 0.5 단위(부분 청산) => revenue=? PnL=? 잔여 포지션=?
	3.	가격 더 올라 120달러 → sell 0.5 남은 포지션 전부 => revenue=? PnL=? 최종 balance=?
	4.	최종 portfolio_value=?

이렇게 중간단계별로 “내가 기대하는 값”을 써둔 뒤, 실제 backtester를 돌리고, 각 단계별로 assert해보면, 부분 청산 / 평단 계산 / revenue vs pnl / balance 업데이트가 제대로 맞아떨어지는지 알 수 있습니다.

6) 결론 & 권장 접근
	1.	매도 시점: “롱 포지션 청산” vs “숏 포지션 신규 진입”을 로직상 분리해서, 정확히 revenue & PnL 계산.
	2.	부분 청산 로직: (sell_size, realized_pnl, net_revenue) → balance 갱신, positions[asset] 감소, entry_price 조정
	3.	포지션 크기 제한: 최종 trade_size 계산할 때 한 번 더 max_position_value 체크해서 trade_value <= max_position_value.
	4.	테스트:
	•	(a) “단일 시나리오” 테스트 (buy→sell 부분청산→sell 전부청산) 식으로 하나씩 검증
	•	(b) tolerance(±0.01) 허용
	5.	중복 기록: execute_trade 내부의 self.trades.append(...) 제거하고, run 메서드(혹은 바깥)에서만 self.trades.append(...).

위 단계를 적용하면,
	•	“10.93% vs 10%” 문제는 “절대 10.0% 넘지 않도록” 로직에서 잘라 내서 해결
	•	PnL이 0.7~0.8 정도 차이 나는 문제는 “부분 청산 로직”을 좀 더 정확히 해 주면 대부분 없어짐.
	•	“revenue=None” 문제도, “long 청산” vs “short 진입”을 구분해서, 실제 청산인 경우엔 trade_revenue를 정확히 계산해 넣으면 해결
	•	“average trade=0” 문제는 실제로 손익이 너무 작거나 fee가 많으면 충분히 0 근처 가능 → 필요하면 테스트 데이터를 더 큰 변동성으로 만들어 보세요.

정리하자면, 현재 테스트에서 발생하는 pnl 미스매치나 position size 초과 문제는 “실제 거래와 유사한 부분 청산+평단 로직”을 좀 더 정확히 구현하면 대부분 해결됩니다. 이 로직이 단순화되어 있다 보니, 테스트와 실제 기대값이 조금씩 달라지는 겁니다.

최종 팁: 구현을 간소화하려면,
	•	“숏 진입”은 별도 로직(혹은 지금은 지원 안 함)
	•	“매도 action < 0” = “기존 롱 포지션 청산(부분/전부)”
	•	“매수 action > 0” = “롱 포지션 진입(추가매수)”
등으로 나눠서, “포지션 방향은 오직 롱만. 매도는 청산만.” → 이렇게 하면 revenue/pnl 계산이 훨씬 깔끔해집니다.
그 뒤 숏까지 지원하려면, “기존 포지션이 0 or 음수인지”를 분리해서 처리하면 됩니다.

이 과정을 단계별로 시행하고, 매 스텝마다 “내가 기대하는 수치”와 “백테스터가 계산한 수치”를 비교하는 상세 테스트를 작성해 두면, 앞으로도 안정적으로 동작할 것입니다.


아래는 “코어 로직은 최대한 건드리지 않고, 다른 기존 테스트도 깨뜨리지 않으면서, 현재 test_trade_execution_logging 등의 문제(매도 시 revenue 누락, PnL 미스매치, 포지션 사이즈 초과)를 우회 혹은 보완할 수 있도록” 유도하는 예시 프롬프트입니다.
또한 “수정 후에는 꼭 python -m pytest tests/ -v로 테스트를 돌려 결과를 확인”하도록 하는 과정을 단계적으로 안내해 줍니다.

class ExperimentalBacktester(RiskAwareBacktester):
    """Experimental backtester with improved position management and PnL calculation."""
    
    def __init__(self, data: pd.DataFrame, risk_config: RiskConfig, initial_balance: float = 10000.0):
        super().__init__(data=data, risk_config=risk_config, initial_balance=initial_balance)
        self.entry_prices: Dict[str, float] = {}  # Track entry prices per asset
        self.positions: Dict[str, float] = {}     # Track positions per asset
    
    def _enforce_position_limits(self, trade_size: float, current_price: float) -> float:
        """Enforce position size limits strictly."""
        portfolio_value = self._calculate_portfolio_value()
        max_position_value = self.risk_config.max_position_size * portfolio_value
        trade_value = abs(trade_size) * current_price
        
        if trade_value > max_position_value:
            # Scale down trade size to exactly match limit
            scale = max_position_value / trade_value
            trade_size *= scale * 0.99  # Add 1% buffer to ensure we're under limit
        
        return trade_size
    
    def _calculate_trade_revenue(self, asset: str, trade_size: float, current_price: float) -> Dict[str, float]:
        """Calculate trade revenue and PnL for position closure."""
        old_pos = self.positions.get(asset, 0)
        entry_price = self.entry_prices.get(asset, current_price)
        
        if trade_size < 0 and old_pos > 0:  # Closing long position
            # Calculate actual closure size
            close_size = min(abs(trade_size), old_pos)
            
            # Calculate gross revenue and fees
            gross_revenue = close_size * current_price
            fee = gross_revenue * self.trading_fee
            net_revenue = gross_revenue - fee
            
            # Calculate realized PnL
            realized_pnl = close_size * (current_price - entry_price) - fee
            
            return {
                "revenue": net_revenue,
                "pnl": realized_pnl,
                "close_size": close_size
            }
        
        # For new positions or position increases
        trade_value = abs(trade_size) * current_price
        fee = trade_value * self.trading_fee
        
        if trade_size > 0:  # Opening/increasing long position
            return {
                "cost": trade_value + fee,
                "pnl": -fee,
                "close_size": 0
            }
        else:  # Opening short position (if allowed)
            return {
                "revenue": trade_value - fee,
                "pnl": -fee,
                "close_size": 0
            }
    
    def execute_trade(self, timestamp: pd.Timestamp, action: float, price_data: Dict[str, float]) -> Dict[str, Any]:
        """Execute trade with improved position management and PnL calculation."""
        if abs(action) < self.risk_config.min_trade_size:
            return {
                "timestamp": timestamp,
                "action": "skip",
                "reason": "action too small",
                "position": sum(self.positions.values())
            }
        
        current_price = price_data.get("$close", price_data.get("close"))
        if not current_price:
            raise ValueError("Price data must contain 'close' or '$close'")
        
        # Calculate initial trade size
        portfolio_value = self._calculate_portfolio_value()
        trade_size = action * portfolio_value / current_price
        
        # Enforce position limits strictly
        trade_size = self._enforce_position_limits(trade_size, current_price)
        
        # Default asset key (for single-asset backtesting)
        asset = "default"

        trade_details = self._calculate_trade_revenue(asset, trade_size, current_price)

            close_size = trade_details["close_size"]
            if close_size > 0:
                self.positions[asset] = self.positions.get(asset, 0) - close_size
                if abs(self.positions[asset]) < 1e-8:
                    del self.positions[asset]
                    del self.entry_prices[asset]
        
        if trade_size > 0:  # Opening/increasing long position
            new_position = self.positions.get(asset, 0) + trade_size
            self.positions[asset] = new_position
            # Update entry price with weighted average
            old_value = self.positions.get(asset, 0) * self.entry_prices.get(asset, current_price)
            new_value = trade_size * current_price
            self.entry_prices[asset] = (old_value + new_value) / new_position
        
        # Update balance
        if "cost" in trade_details:
            self.balance -= trade_details["cost"]
        if "revenue" in trade_details:
            self.balance += trade_details["revenue"]
        
        # Prepare trade result
        trade_result = {
            "timestamp": timestamp,
            "type": "buy" if trade_size > 0 else "sell",
            "price": current_price,
            "size": abs(trade_size),
            "position": sum(self.positions.values()),
            "balance": self.balance,
            "portfolio_value": self._calculate_portfolio_value()
        }
        
        # Add revenue/cost and PnL
        trade_result.update({k: v for k, v in trade_details.items() 
                           if k in ["revenue", "cost", "pnl"]})
        
        # Record trade
        self.trades.append(trade_result)
        
        return trade_result

import pandas as pd

from risk.risk_manager import RiskConfig

class ExperimentalBacktester(BacktestEngine):
    """Experimental backtester with improved position management and PnL calculation."""

        super().__init__(
            initial_capital=initial_balance,
            transaction_cost=0.001,  # Default trading fee
            max_position=risk_config.max_position_size
        )
        self.data = data
        self.risk_config = risk_config
        self.entry_prices: Dict[str, float] = {}  # Track entry prices per asset
        self.positions: Dict[str, float] = {}     # Track positions per asset
        self.trading_fee = 0.001  # For compatibility with tests

        """Calculate trade revenue and PnL for position closure."""
        old_pos = self.positions.get(asset, 0)
        entry_price = self.entry_prices.get(asset, current_price)

            # Calculate actual closure size
            close_size = min(abs(trade_size), old_pos)
            
            # Calculate gross revenue and fees
            gross_revenue = close_size * current_price
            fee = gross_revenue * self.trading_fee
            net_revenue = gross_revenue - fee
            
            # Calculate realized PnL
            realized_pnl = close_size * (current_price - entry_price) - fee
            
            return {
                "revenue": net_revenue,
                "pnl": realized_pnl,
                "close_size": close_size
            }
        
        # For new positions or position increases
        trade_value = abs(trade_size) * current_price
        fee = trade_value * self.trading_fee
        
        if trade_size > 0:  # Opening/increasing long position
            return {
                "cost": trade_value + fee,
                "pnl": -fee,
                "close_size": 0
            }
        else:  # Opening short position (if allowed)
            return {
                "revenue": trade_value - fee,
                "pnl": -fee,
                "close_size": 0
            }
    
    def execute_trade(self, timestamp: pd.Timestamp, action: float, price_data: Dict[str, float]) -> Dict[str, Any]:
        """Execute trade with improved position management and PnL calculation."""
        if abs(action) < self.risk_config.min_trade_size:
            return {
                "timestamp": timestamp,
                "action": "skip",
                "reason": "action too small",
                "position": sum(self.positions.values())
            }
        
        current_price = price_data.get("$close", price_data.get("close"))
        if not current_price:
            raise ValueError("Price data must contain 'close' or '$close'")
        
        # Calculate portfolio value and maximum allowed position
        portfolio_value = self.get_portfolio_value({"default": current_price})
        max_position_value = portfolio_value * self.risk_config.max_position_size
        max_position_size = max_position_value / current_price

        asset = "default"
        current_position = self.positions.get(asset, 0)
        
        if action < 0 and current_position > 0:  # Closing long position
            # Calculate closure size based on current position
            # action = -0.25 means close 50% of current position (2 * abs(action))
            close_size = current_position * (2 * abs(action))
            trade_size = -close_size
            
            # For complete closure (action <= -0.5), close entire position
            if abs(action) >= 0.5:
                trade_size = -current_position
        else:  # Opening new position or adding to position
            # Calculate target position size based on action
            # action = 0.5 means target 50% of max_position_size
            target_size = max_position_size * action * 0.99  # Add 1% buffer
            
            # Calculate required trade size
            trade_size = target_size - current_position
            
            # Ensure we don't exceed position limits
            new_position_value = (current_position + trade_size) * current_price
            if new_position_value > max_position_value:
                trade_size = (max_position_value / current_price - current_position) * 0.99
        
        # Calculate trade details
        trade_details = self._calculate_trade_revenue(asset, trade_size, current_price)
        
        # Update positions and entry prices
        if trade_size < 0 and current_position > 0:  # Position closure
            close_size = min(abs(trade_size), current_position)
            new_position = current_position - close_size
            
            if abs(new_position) < 1e-8 or abs(action) >= 0.5:  # Complete closure
                del self.positions[asset]
                del self.entry_prices[asset]
            else:  # Partial closure
                self.positions[asset] = new_position
        elif trade_size > 0:  # Opening/increasing long position
            new_position = current_position + trade_size
            self.positions[asset] = new_position
            
            # Update entry price with weighted average
            if current_position > 0:
                # Calculate weighted average of old and new positions
                old_value = current_position * self.entry_prices[asset]
                new_value = trade_size * current_price
                total_size = current_position + trade_size
                self.entry_prices[asset] = (old_value + new_value) / total_size
            else:
                # For new positions, use the current price
                self.entry_prices[asset] = current_price

        if "cost" in trade_details:
            self.cash -= trade_details["cost"]
        if "revenue" in trade_details:
            self.cash += trade_details["revenue"]
        
        # Prepare trade result
        trade_result = {
            "timestamp": timestamp,
            "type": "buy" if trade_size > 0 else "sell",
            "price": current_price,
            "size": abs(trade_size),
            "position": sum(self.positions.values()),
            "balance": self.cash,
            "portfolio_value": self.get_portfolio_value({"default": current_price})
        }
        
        # Add revenue/cost and PnL
        trade_result.update({k: v for k, v in trade_details.items() 
                           if k in ["revenue", "cost", "pnl"]})
        
        # Record trade
        self.trades.append(trade_result)
        
        return trade_result

        max_position_value = portfolio_value * self.risk_config.max_position_size

        trade_details = self._calculate_trade_revenue(asset, trade_size, current_price)

                new_value = trade_size * current_price
                total_size = current_position + trade_size
                self.entry_prices[asset] = (old_value + new_value) / total_size

                self.entry_prices[asset] = current_price

            self.cash -= trade_details["cost"]
        if "revenue" in trade_details:
            self.cash += trade_details["revenue"]

        # Add revenue/cost and PnL
        trade_result.update({k: v for k, v in trade_details.items() 
                           if k in ["revenue", "cost", "pnl"]})
        
        # Record trade
