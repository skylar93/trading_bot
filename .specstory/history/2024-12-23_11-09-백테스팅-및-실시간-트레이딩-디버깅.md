## 정리해보면 해결해야 할 핵심 포인트

### A. **Mock DataFrame에 `"bid"` 컬럼을 추가**  
- 현재 `_get_observation()` 메서드 안에서 `for col in ["bid", "ask", "last_price", ...]: df[col].values` 같이 접근하고 있을 거예요.  
- 그런데 테스트에서 mocking한 데이터에는 `"bid"` 키가 없음 → KeyError  
- 해결책: **테스트용 Mock DataFrame**(혹은 WebSocket Mock)이 `"bid"`, `"ask"`, `"last_price"`, `"volume"` 등 필요한 컬럼을 전부 갖도록 생성해야 함.  
- 예를 들어:

  ```python
  mock_data = pd.DataFrame({
      "bid": [1.1001, 1.1002, 1.1003, ...],
      "ask": [1.1005, 1.1006, 1.1007, ...],
      "last_price": [1.1003, 1.1004, 1.1003, ...],
      "volume": [100, 120, 90, ...],
      ...
  })
  ```

- **주의**: 여러 테스트에서 각각 다른 mock 데이터를 사용할 수 있으니, fixture나 test 함수별로 일관성 있게 컬럼을 만들어줘야 해요.

### B. **`create_order`가 실제로 호출되지 않는 문제**  
- Mock 객체(`live_env.exchange.create_order`)의 `call_count`가 0이면, 실제 코드 어디에도 `exchange.create_order(...)`가 실행되지 않았다는 뜻  
- 확인 방법:  
  1. **LiveTradingEnvironment** 내부에서 `action`을 해석해 “주문을 생성할 조건”이 충족되었는지  
  2. `action > 0.0`이면 `create_order(...)`를 호출하도록 로직이 있는지  
  3. 만약 부분 체결로직이 “아직 주문을 안 내도 된다”라고 판단하면 호출이 안 될 수도  
  4. 혹은 "MockExchange"와 "RealExchange" 로직이 달라서, Mock일 때 order를 생성 안 하는 경우도 있음  
- 해결책:  
  - **step()** 또는 **_execute_action()** 등에서 action이 매수/매도 조건을 충족하면 `exchange.create_order(...)` 호출하도록 보장  
  - 디버그 출력(예: `print("CREATING ORDER:", size, price)")`)을 넣어봐서 코드가 실제로 타는지 확인  
  - 주문을 낼 때 “테스트 모드”와 “라이브 모드”가 다르게 동작하면 안 됨 (테스트 모드에서도 `create_order`를 호출해야 call_count가 증가)

### C. **포지션이 0이 아닌 소수점 (~0.004)로 남는 문제**  
- 부분 체결 시 남은 포지션을 0으로 수렴시키지 않고 있음  
- 예: “최소 거래 단위” 혹은 “잔고가 1e-3 미만이면 0으로 처리” 같은 로직이 제대로 작동하지 않음  
- 해결책:  
  - step 후에 `if abs(self.position) < 1e-3: self.position = 0.0` 같은 식으로 **임계값 처리**  
  - 혹은 partial fill을 100% 완전히 체결되도록 mocking → 이 경우 테스트 상황에서 "매수/매도하면 전부 체결" 식으로 단순화  
  - **테스트 의도**가 “네트워크 지연 시 주문이 부분적으로만 체결되어 소수점이 남아도 괜찮다”인지, “실패 시에는 포지션이 완전 0이어야 한다”인지 명확히 정의해야 함

### D. **관측 창 size mismatch (10 vs 30)**  
- `test_environment_initialization`에서 `assert obs.shape == (10, 13)`이 기대되나 실제 `(30, 13)`  
- 일반적으로는 `window_size = 10`이라면 최근 10개 행만 slicing 해야 함 (예: `df.iloc[-10:]`)  
- 어디선가 `df[-self.window_size*3:]`처럼 30개를 잘못 읽고 있거나, mock_data가 30행이 생성된 뒤 slicing이 안 됐을 수 있음.  
- 해결책:  
  - `_get_observation()` 안에 `df = df.iloc[-self.window_size:]` 로직을 확실히 넣어서 “정말 window_size행만” 자르도록 보장

### E. **테스트마다 기대 포지션이 달라서 충돌**  
- “test_network_delay_handling”에서 포지션이 0이길 바라지만, 일부 체결로 남아버려서 0.004…  
- “test_basic_trading”에서는 포지션이 > 0이어야 하는데 0.0으로 남음  
- 이는 테스트 시나리오와 실제 구현 시나리오가 어긋나 있기 때문.  
- 해결책:  
  - 각 테스트가 의도한 시나리오(“주문 체결 성공 여부”, “부분 체결률”, “지연 시 재시도”)를 정확히 매핑해야 함  
  - 만약 “지연 핸들링 테스트”는 “아무 주문도 체결되지 않는다”가 목표라면, 코드에서 `if network_delay: skip order?` 같은 로직이 필요  
  - 반대로 “오류 핸들링” 시나리오는 “오류나면 즉시 포지션=0”으로 강제 청산? → 그런 정책을 코드에 반영해야 함

## **구체적인 수정 전략**

1. **Mock 데이터에 `"bid"` 컬럼 추가**  
   - 테스트 픽스처에서 DataFrame 생성 시 bid/ask/last_price 등 필요한 컬럼 전부 채워넣기
   - 예:  

     ```python
     @pytest.fixture
     def mock_websocket_data():
         df = pd.DataFrame({
             "timestamp": [...],
             "bid": [1.2, 1.201, 1.202, ...],
             "ask": [1.21, 1.211, 1.212, ...],
             "last_price": [1.205, 1.206, 1.207, ...],
             "volume": [...],
             # ... etc
         })
         return df
     ```
     
   - 그리고 `_get_observation()`에서 `col in ["bid", "ask", "last_price", "volume"]` 등으로 데이터 가져온 뒤 slicing

2. **테스트 환경에서 주문이 실제로 생성되도록 코드 흐름 점검**  
   - LiveTradingEnvironment.step() → action 해석 → 조건 만족 시 `self.exchange.create_order(...)`  
   - mock_exchange를 AsyncMock으로 만들었다면 `await self.exchange.create_order(...)`로 호출  
   - call_count 체크하려면 “`await`로 실질 호출”이 이뤄져야 하므로, 중간에 “if self.test_mode: return” 같은 로직이 있으면 안 됨

3. **포지션 임계값 처리**  
   - step() 끝나고 나서:  
     ```python
     if abs(self.position) < 1e-3:
         self.position = 0.0
     ```
   - 테스트가 "완벽히 0"을 기대한다면 임계값을 더 높일 수도 있음(e.g. `1e-2`)

4. **각 테스트의 시나리오 구체화**  
   - `test_network_delay_handling`:  
     - 의도: “네트워크 지연이 심해 주문이 전혀 체결되지 않는다 → 포지션이 0”  
     - → 구현에서 network_delay가 True면 `create_order` 자체가 안 일어나거나, 주문 모니터링이 실패해서 포지션=0.0이 되어야 함  
   - `test_error_handling`:  
     - 의도: “오류 발생 시 포지션이 즉시 0으로 강제 정리된다”  
     - → step() 안에서 오류 감지하면 `self.position = 0`으로 설정  
   - `test_basic_trading`:  
     - 의도: “매수하면 포지션 > 0”  
     - → partial fill이라도 최소 몇 %는 체결되어야 포지션이 양수가 됨  
     - mock에서 partial fill=1.0 (100% 체결)로 단순화하면 편함

5. **Observation window size 고정**  
   - `_get_observation()`에서 `df = df.iloc[-self.window_size:] if len(df) > self.window_size else df`  
   - 이렇게 해서 항상 (window_size, n_features) 형태를 보장

### **정리**

- **`bid` KeyError**:  
  1) **Mock DataFrame**에 `"bid"`(및 `"ask"`, `"last_price"`) 열이 없어서 발생  
  2) 해결: 테스트 픽스처나 `mock_websocket_data`에서 컬럼 생성

- **포지션=0 vs 0.004**:  
  1) 부분 체결/에러 시나리오와 테스트 기대치가 안 맞음  
  2) 해결: step 로직에서 **임계값 이하 → 0** 처리, 또는 테스트 시나리오 재설계

- **create_order call_count=0**:  
  1) 주문 로직을 호출하는 분기문이 안 타거나, mock이 잘못돼서 호출이 무시됨  
  2) 해결: `step()` 안에서 확실히 `await self.exchange.create_order(...)` 실행, 그리고 mock이 AsyncMock으로 설정되어 있는지 확인

- **(30,13) vs (10,13)**:  
  1) window_size mismatch  
  2) 해결: `_get_observation()`에서 `df.iloc[-self.window_size:]` 하도록 고정

이 네 가지를 확실히 잡으면 대부분의 테스트 이슈가 사라질 거예요. “네트워크 지연 시나리오”나 “error handling 시나리오” 등에 대해서도 “테스트의 의도”와 “코드의 구현”이 합치하도록 주의해야 합니다.

async def step(self, action: np.ndarray) -> Tuple[np.ndarray, float, bool, bool, Dict]:
        """Execute one step in the environment"""
        try:
            # Get current price and portfolio value before action
            current_price = self._last_price if self.test_mode else self.websocket.get_latest_price()
            portfolio_value_before = self.portfolio_value

            # Parse action
            action_value = float(action[0])  # Convert to float
            
            # Skip if action is too small
            if abs(action_value) < 0.01:
                return await self._get_observation(), 0.0, False, False, self._get_info()

            # Calculate order size
            if action_value > 0:  # Buy
                max_buy_amount = self.balance / current_price
                order_size = max_buy_amount * action_value
                side = "buy"
            else:  # Sell
                order_size = abs(self.position * action_value)
                side = "sell"

            # Skip if order size is too small
            if order_size * current_price < 10.0:  # Minimum order value
                return await self._get_observation(), 0.0, False, False, self._get_info()

            try:
                # Create and monitor order
                order_id = await self.create_order(side, order_size, current_price)
                if order_id:
                    async for order_update in self.monitor_order(order_id):
                        if order_update['status'] in [OrderStatus.CLOSED, OrderStatus.CANCELED]:

                            if filled_amount > 0:
                                if side == "buy":
                                    self.position += filled_amount
                                    self.balance -= filled_amount * current_price * (1 + self.trading_fee)
                                else:
                                    self.position -= filled_amount
                                    self.balance += filled_amount * current_price * (1 - self.trading_fee)
                            break

            except Exception as e:
                logger.error(f"Error executing order: {e}")
                return await self._get_observation(), -1.0, False, False, self._get_info()

            # Apply position threshold
            if abs(self.position) < 1e-3:
                self.position = 0.0

            # Calculate reward
            portfolio_value_after = self.portfolio_value
            reward = (portfolio_value_after - portfolio_value_before) / portfolio_value_before

            # Get observation and info
            obs = await self._get_observation()
            info = self._get_info()

                    id=order_id,
                    symbol=self.symbol,
                    type="limit",
                    side=side,
                    amount=amount,
                    price=price,

    async def step(self, action: np.ndarray) -> Tuple[np.ndarray, float, bool, bool, Dict]:
        """Execute one step in the environment"""
        try:
            # Get current price and portfolio value before action
            current_price = self._last_price if self.test_mode else self.websocket.get_latest_price()
            portfolio_value_before = float(self.portfolio_value)

            # Parse action
            action_value = float(action[0])  # Convert to float
            
            # Skip if action is too small
            if abs(action_value) < 0.01:
                return await self._get_observation(), 0.0, False, False, self._get_info()

            # Calculate order size
            if action_value > 0:  # Buy
                max_buy_amount = (self.balance * 0.99) / current_price  # Leave some margin for fees
                order_size = max_buy_amount * action_value
                side = "buy"
            else:  # Sell
                order_size = abs(self.position * action_value)
                side = "sell"

            # Skip if order size is too small
            if order_size * current_price < 10.0:  # Minimum order value
                return await self._get_observation(), 0.0, False, False, self._get_info()

            try:
                # Create and monitor order
                order_id = await self.create_order(side, order_size, current_price)
                if not order_id:  # Order creation failed
                    logger.warning("Order creation failed")
                    self._reset_position()
                    return await self._get_observation(), -1.0, False, False, self._get_info()

                async for order_update in self.monitor_order(order_id):
                    if order_update['status'] in [OrderStatus.CLOSED, OrderStatus.CANCELED]:
                        # Update position and balance based on filled amount
                        filled_amount = float(order_update.get('filled', 0))
                        if filled_amount > 0:
                            if side == "buy":
                                new_position = round(self.position + filled_amount, 8)
                                new_balance = round(self.balance - filled_amount * current_price * (1 + self.trading_fee), 8)
                            else:
                                new_position = round(self.position - filled_amount, 8)
                                new_balance = round(self.balance + filled_amount * current_price * (1 - self.trading_fee), 8)
                            
                            # Apply updates only if they are valid
                            if new_balance >= 0 and np.isfinite(new_position) and np.isfinite(new_balance):
                                self.position = new_position
                                self.balance = new_balance
                            else:
                                self._reset_position()
                        break

            except (ccxt.NetworkError, ccxt.ExchangeError, ccxt.RateLimitExceeded) as e:
                logger.error(f"Exchange error: {e}")
                self._reset_position()
                return await self._get_observation(), -1.0, False, False, self._get_info()
            except Exception as e:
                logger.error(f"Unexpected error: {e}")
                self._reset_position()
                return await self._get_observation(), -1.0, False, False, self._get_info()

            # Apply position threshold
            if abs(self.position) < 1e-6:  # Stricter threshold
                self.position = 0.0

            # Calculate reward
            portfolio_value_after = float(self.portfolio_value)
            if portfolio_value_before > 0:

            else:

                reward = -1.0

            # Get observation and info
            obs = await self._get_observation()
            info = self._get_info()

            return obs, reward, False, False, info

                    status = {
                        'id': order_id,
                        'status': OrderStatus.CANCELED,
                        'filled': 0.0,

                    self._update_mock_data()

                    error_count = 0  # Reset error count on successful status check
                except Exception as e:

                    yield status

                    OrderStatus.CANCELED,
                    OrderStatus.EXPIRED,

        start_time = datetime.now()
        last_status = None
        error_count = 0
        max_errors = 3
        
        while True:
            try:
                # Check if order exists
                if order_id not in self.active_orders:
                    status = {
                        'id': order_id,
                        'status': OrderStatus.CANCELED,
                        'filled': 0.0,
                        'remaining': 0.0,
                        'price': 0.0
                    }

                    yield status
                    break

                if self.test_mode:
                    self._update_mock_data()

                    error_count = 0  # Reset error count on successful status check

                    error_count += 1
                    if error_count >= max_errors:
                        logger.error("Max error count reached, canceling order")
                        self._reset_position()
                        status = {
                            'id': order_id,
                            'status': OrderStatus.REJECTED,
                            'filled': 0.0,
                            'remaining': 0.0,
                            'price': 0.0
                        }
                        yield status
                        break
                    continue

                if status != last_status:
                    yield status

                    OrderStatus.CLOSED,
                    OrderStatus.CANCELED,
                    OrderStatus.EXPIRED,
                    OrderStatus.REJECTED

                        await self.cancel_order(order_id)
                    except Exception as e:

        start_time = datetime.now()
        last_status = None
        error_count = 0
        max_errors = 3
        
        while True:
            try:
                # Check if order exists
                if order_id not in self.active_orders:
                    status = {
                        'id': order_id,
                        'status': OrderStatus.CANCELED,
                        'filled': 0.0,
                        'remaining': 0.0,

                    yield status

                    self._update_mock_data()

                    status = await self.check_order_status(order_id)
                    error_count = 0  # Reset error count on successful status check
                except Exception as e:
                    logger.error(f"Error checking order status: {e}")
                    error_count += 1
                    if error_count >= max_errors:
                        logger.error("Max error count reached, canceling order")
                        self._reset_position()
                        status = {
                            'id': order_id,
                            'status': OrderStatus.REJECTED,
                            'filled': 0.0,
                            'remaining': 0.0,
                            'price': 0.0
                        }
                        yield status
                        break
                    continue

                if status != last_status:
                    yield status
                    last_status = status.copy()

                if status['status'] in [
                    OrderStatus.CLOSED,
                    OrderStatus.CANCELED,
                    OrderStatus.EXPIRED,
                    OrderStatus.REJECTED

    async def monitor_order(self, order_id: str, timeout: float = 30.0) -> AsyncGenerator[Dict, None]:
        """Monitor order status until it's filled or canceled"""
        start_time = datetime.now()
        last_status = None
        error_count = 0
        max_errors = 3
        
        while True:
            try:
                # Check if order exists
                if order_id not in self.active_orders:
                    status = {
                        'id': order_id,
                        'status': OrderStatus.CANCELED,
                        'filled': 0.0,
                        'remaining': 0.0,
                        'price': 0.0
                    }
                    self._reset_position()
                    yield status
                    break

                # Update mock data in test mode
                if self.test_mode:
                    self._update_mock_data()
                
                # Get order status
                try:
                    status = await self.check_order_status(order_id)
                    error_count = 0  # Reset error count on successful status check
                except Exception as e:
                    logger.error(f"Error checking order status: {e}")
                    error_count += 1
                    if error_count >= max_errors:
                        logger.error("Max error count reached, canceling order")
                        self._reset_position()
                        status = {
                            'id': order_id,
                            'status': OrderStatus.REJECTED,
                            'filled': 0.0,
                            'remaining': 0.0,
                            'price': 0.0
                        }
                        yield status
                        break
                    continue
                
                # Yield only if status changed
                if status != last_status:
                    yield status
                    last_status = status.copy()
                
                # Break if order is complete
                if status['status'] in [
                    OrderStatus.CLOSED,
                    OrderStatus.CANCELED,
                    OrderStatus.EXPIRED,
                    OrderStatus.REJECTED
                ]:
                    # Reset position if order failed or had no fill
                    if status['status'] in [OrderStatus.CANCELED, OrderStatus.EXPIRED, OrderStatus.REJECTED] or \
                       (status['status'] == OrderStatus.CLOSED and status.get('filled', 0) == 0):
                        self._reset_position()
                    break
                
                # Check timeout
                if (datetime.now() - start_time).total_seconds() > timeout:
                    logger.warning(f"Order {order_id} monitoring timed out")
                    # Cancel order and reset position on timeout
                    try:
                        await self.cancel_order(order_id)
                    except Exception as e:
                        logger.error(f"Error canceling order on timeout: {e}")
                    self._reset_position()
                    status = {
                        'id': order_id,
                        'status': OrderStatus.CANCELED,
                        'filled': 0.0,
                        'remaining': 0.0,
                        'price': 0.0
                    }
                    yield status
                    break
                
                await asyncio.sleep(0.5)  # Increased sleep time
                
            except Exception as e:
                logger.error(f"Error monitoring order {order_id}: {e}")
                error_count += 1
                if error_count >= max_errors:
                    logger.error("Max error count reached in monitor_order")
                    self._reset_position()
                    status = {
                        'id': order_id,
                        'status': OrderStatus.REJECTED,
                        'filled': 0.0,
                        'remaining': 0.0,
                        'price': 0.0
                    }
                    yield status
                    break
                await asyncio.sleep(0.5)  # Sleep before retry
